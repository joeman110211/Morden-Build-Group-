# Morden Build Group website

A responsive, single-page website concept for Morden Build Group, built with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser. No build tools or package installation are required.

## Included
- Responsive desktop and mobile layout
- Services, about, project gallery, process, FAQs and contact sections
- Mobile sticky call/quote actions
- Accessible mobile navigation and FAQ accordions
- Quote enquiry form that prepares a draft in the visitor's email app

## Before publishing
1. Confirm the official phone number, email address, service area and legal business name.
2. Replace the sample project photos with Morden Build Group's own authorised project images.
3. Verify all insurance, licensing, emergency-response and experience claims before adding them.
4. Connect the quote form to a real email recipient or a form service. The current demo uses a `mailto:` link and does not send enquiries to a business automatically.
5. Add privacy and cookie information if required, then test mobile layouts, links, SEO and accessibility.
6. Configure hosting and the custom domain. GitHub stores the source; it does not automatically make the site live.

## Tech
Plain HTML, CSS and JavaScript. External photography is loaded from Unsplash URLs; replace with owned/licensed images for production.
